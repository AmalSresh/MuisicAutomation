- Exact runtime visual values belong in ../../frontend/src/styles/tokens.css once supplied and implemented.

Agents must read this index and applicable references before UI work. Product requirements govern behavior and scope; designs govern appearance. Report conflicts. Never invent approved assets or silently redesign a screen.
