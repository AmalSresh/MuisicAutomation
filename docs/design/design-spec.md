# Shared design specification

Status: awaiting user-supplied design choices. No visual values are approved here.

Record font family/weights, typography scale, layout/window sizes, resizing behavior, spacing, radii, shadows, component dimensions, and hover/focus/disabled/loading/error/empty states when supplied. Use semantic token names for exact colors and values in the actual frontend token file; do not maintain competing value lists.

Use original brand assets and reusable components. Preserve keyboard support, visible focus, screen-reader labels, high contrast and 200% scaling. Before completing UI work, compare the rendered result with the approved reference at the documented window size and report missing or unverified states.
